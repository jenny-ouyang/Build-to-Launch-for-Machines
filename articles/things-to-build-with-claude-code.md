# How to Use Claude Code for Real Problems, Not Just App Ideas

**URL:** https://buildtolaunch.substack.com/p/things-to-build-with-claude-code
**Track:** AI Builders Playbook
**Published:** 2026-05-27

## Summary

Most Claude Code guides frame it as an app-building tool — personal websites, expense trackers, SaaS products. This article takes a different angle: 19 starting points drawn from real daily friction across work, personal life, and family time, each shown across four build levels so you can match the solution to how often the problem actually comes back.

The four levels are: Task (do it once, right now, no setup), Workflow (a skill or slash command you build once so it runs the same way every time), App (ship it so others can use it without a terminal), and Agent (scheduled and connected to your real accounts, runs without you). The rule throughout is to stop at the level that solves the problem — a Task that takes five minutes is worth more than an Agent built for something that only comes up once a month.

Work builds include document Q&A on local files (a 40-page contract reviewed in 4 minutes instead of 90), CSV and survey qualitative analysis, content repurposing in your actual voice using CLAUDE.md voice rules, literature review and research synthesis, job search briefing, and competitive intelligence scanning on a weekly schedule. Each is shown from paste-and-ask at Task level through a fully scheduled Agent. Personal builds cover market research before purchases, negotiation prep with objection scripts, travel planning with pre-loaded preferences, deal and price tracking, file organization, and home reappraisal/financial dispute preparation — including Jenny's documented case of successfully challenging a property tax assessment. Family builds include math practice worksheets, grammar drills, craft step-guides in child-readable language, drawing guides, rainy day activity generators with kids' context pre-loaded, and a curiosity explainer for the questions kids ask that parents can't answer on the spot.

The closing framework for picking a level is two questions: how often does this problem come back, and who else has it. Weekly or daily recurrence justifies a Workflow; if others share the friction, an App earns its build time. The article closes with a 99-build map covering all friction points at Task level entry prompts, available at resources.buildtolaunch.ai.
