# Claude Skills: What They Are, How They Actually Work, and How They Compare to GPTs and Gems

**URL:** https://buildtolaunch.substack.com/p/claude-skills-claude-code-vs-chatgpt-gpts-gemini-gems
**Track:** AI Builders Playbook
**Published:** 2025-11-25

## Summary

Claude Skills are Anthropic's answer to ChatGPT GPTs and Gemini Gems: saved workflows that load into Claude automatically, so you stop re-explaining your process every session. Most coverage stops at that feature description. This guide goes further into the parts that decide whether a skill is actually useful — the four types most people don't know they can use, the description-field mechanic that determines whether a skill ever fires, the ten-dimension comparison with GPTs and Gems, and what six months of running 30+ skills daily taught that the docs don't cover.

It begins by defining what skills really are, then lays out the four types available today and shows what an actual SKILL.md file looks like, using a Substack Notes skill as the worked example — its seven formulas, the formula-selection logic, and the scheduling rules. That concrete file makes the abstract idea legible: a skill is a markdown file with instructions and rules, not a black box.

The middle builds toward how skills behave in practice. It walks through building a first skill, the relationship between Claude Code skills and Claude.ai skills (same format, different home), and how skills work under the hood. A "confusion decoder" section separates skills from projects, prompts, and MCP — the four things people constantly mix up — before the head-to-head comparison of Claude Skills, ChatGPT GPTs, and Gemini Gems across ten real dimensions, and a note on the open standard underneath that nobody talks about.

The final sections are about judgment: who skills are actually for, when to skip them, the floor everyone forgets, and what a real production skills system looks like once you're running many at once. It closes with next steps and an FAQ. The recurring lesson is that the description field — not the skill body — is what controls whether a skill triggers, which is why most skills quietly never run.
